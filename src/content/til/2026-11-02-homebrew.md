Homebrewについて何気なく使っているけど改めて中身を勉強したい

Webブラウザでのダウンロードと何が違うんだろうか？

## `brew`コマンドの正体

実はHomebrewの本体は手元にcloneされたGitリポジトリ

```console
$ git -C /opt/homebrew remote get-url origin

https://github.com/Homebrew/brew
```

`bin/brew`を見ると

`bin/brew:344`

```bash
exec /usr/bin/env -i "${FILTERED_ENV[@]}" /bin/bash -p "${HOMEBREW_LIBRARY}/Homebrew/brew.sh" "$@"
```

`brew.sh`で実行している

そういえば、`bin`フォルダに実行ファイルが多いけど、慣習らしいね
binはbinaryの略語でバイナリファイルを置くのが普通らしいけど、シェルスクリプトが置かれていた
エントリーポイントみたいな意味合いなのかな。

`Library/Homebrew/brew.sh:604`

```bash
if [[ -z "${HOMEBREW_FORCE_RUBY_COMMAND:-}" && -f "${HOMEBREW_LIBRARY}/Homebrew/cmd/${HOMEBREW_COMMAND}.sh" ]]
then
  HOMEBREW_BASH_COMMAND="${HOMEBREW_LIBRARY}/Homebrew/cmd/${HOMEBREW_COMMAND}.sh"
```

`cmd/<コマンド名>.sh`があるか調べる。
コマンド名はディレクトリを見ればわかるが、`brew update`など

`Library/Homebrew/brew.sh:657`

```bash
if [[ -n "${HOMEBREW_BASH_COMMAND}" ]]
then
  source "${HOMEBREW_BASH_COMMAND}"

  {
    auto-update "$@"
    "homebrew-${HOMEBREW_COMMAND}" "$@"
    exit $?
  }

else
  source "${HOMEBREW_LIBRARY}/Homebrew/utils/ruby.sh"
  setup-ruby-path

  [[ "${HOMEBREW_ARG_COUNT}" -gt 0 ]] && set -- "${HOMEBREW_COMMAND}" "$@"
  {
    auto-update "$@"
    exec "${HOMEBREW_RUBY_PATH}" "${HOMEBREW_RUBY_WARNINGS}" "${HOMEBREW_RUBY_DISABLE_OPTIONS}" \
      "${HOMEBREW_LIBRARY}/Homebrew/brew.rb" "$@"
  }
fi
```

Bashで書かれたコマンドならその場で実行で、それ以外はRubyに切り替える。

`Library/Homebrew/brew.rb:132`

```ruby
cmd_class = Homebrew::AbstractCommand.command(cmd)
command_instance = ... { cmd_class.new }
command_instance.run
```

## BashとRubyのコマンド

このBashとRubyで書かれたコマンドはそれぞれ何があるの？

`Library/Homebrew/cmd`を見ると確かにコマンド毎に`.sh`と`.rb`で拡張子が混在する
補足だが`.sh`の16個には、すべて同名の`.rb`がある。

| 場所 | 役割               | .sh | .rb |
| :--- | :----------------- | :-- | :-- |
| cmd/ | 一般向けのコマンド | 16  | 76  |

## `python`とURLのマッピング

installしかあまり使ったことないので、焦点を当てると、
結局ダウンロードすると言うことは、`brew install python`と打ったときにpythonとURLのマッピングをどこかでしているのでは？と思った

ここに書いてあった、これはarm64だけど
`https://formulae.brew.sh/api/internal/packages.arm64_tahoe.jws.json`

GitHub Pagesで配信されていて、`install`するタイミングなどでCPUとOSを判別して、`arm64_tahoe`の箇所を動的に置き換えて取得している。

```text
homebrew-core（Rubyのレシピと別名の定義）
   ↓ brew generate-internal-api
packages.arm64_tahoe.json
   ↓ script/sign-json.rb（署名）
packages.arm64_tahoe.jws.json
   ↓ GitHub Pagesへ配信
https://formulae.brew.sh/api/internal/...
```

さっきのマッピングについてPythonを例にとると、JSONのままだと探しにくいので公開APIで確認する

```console
$ curl -s https://formulae.brew.sh/api/formula/python@3.15.json | python3 -m json.tool | grep -A2 '"stable"'

        "head": null,
        "bottle": true

            "url": "https://www.python.org/ftp/python/3.15.2/Python-3.15.2.tgz",
            "tag": null,

        "stable": {
```

## 実際のダウンロード元

ただし通常、`brew install`で`https://www.python.org/ftp/python/3.15.2/Python-3.15.2.tgz`を使っているわけではないらしい

まず`python`をエイリアスとしてバージョンありに変換する

`https://formulae.brew.sh/api/internal/packages.arm64_tahoe.jws.json`

```text
\"python\":\"python@3.15\"
```

これでコマンドでファイルの保存先を表示できる

```console
$ brew --cache python@3.15

==> Downloading Homebrew API data
✔︎ JSON API packages.arm64_tahoe.jws.json                        Downloaded   16.0MB/ 16.0MB
/Users/user_name/Library/Caches/Homebrew/downloads/4273df50665b548a834b10146e0060b8ab91db77e9eaa52d10b56b0ffa538e03--python@3.15--3.15.2.arm64_tahoe.bottle.tar.gz
```

JSON API にさっきのjsonが使用されていることが書いている。JSONの取得はキャッシュが古い時だけ実行される。
この段階ではまだ、Bottleは保存されていなくて、JSONだけ保存されている。JSONは更新したが、Bottleは取得していない。

```text
4273df50...e03--python@3.15--3.15.2.arm64_tahoe.bottle.tar.gz
└─ URLのハッシュ値  └─ 分かりやすい名前
```

ファイル名の先頭は、ダウンロード元URLのSHA-256ハッシュ値である

`Library/Homebrew/download_strategy/curl_github_packages_download_strategy.rb:34`

```rb
cached_location = HOMEBREW_CACHE/"downloads/#{Digest::SHA256.hexdigest(url)}--#{Utils.safe_filename(@resolved_basename.to_s)}"
```

先ほど、`https://formulae.brew.sh/api/internal/packages.arm64_tahoe.jws.json`を示したが、これは内部的なURLで
公開用の見やすいのは`https://formulae.brew.sh/api/formula/python@3.15.json`である。

[`Library/Homebrew/dev-cmd/generate-formula-api.rb:77`](https://github.com/Homebrew/brew/blob/8f10429b56be28a25032b87463fffc95e556b5bc/Library/Homebrew/dev-cmd/generate-formula-api.rb#L77)

```rb
File.write("_data/formula/#{name.tr("+", "_")}.json", "#{json}\n")
File.write("api/formula/#{name}.json", FORMULA_JSON_TEMPLATE)
```

Formula単位でjsonを吐き出している、こっちは通常`install`に使用しない、人が読みやすいファイル。
さっきのダウンロード元の話に戻ると、

BottleのURLを取り出す

```console
$ curl -s https://formulae.brew.sh/api/formula/python@3.15.json | python3 -c "import json,sys; print(json.load(sys.stdin)['bottle']['stable']['files']['arm64_tahoe']['url'])"

https://ghcr.io/v2/homebrew/core/python/3.15/blobs/sha256:f8927deb45d5d8d6261b514879d9a9750ddaa74ad034514cfd8f89fd8d03dd71
```

2つのURLをハッシュ化して比べる

```console
$ printf %s 'https://ghcr.io/v2/homebrew/core/python/3.15/blobs/sha256:f8927deb45d5d8d6261b514879d9a9750ddaa74ad034514cfd8f89fd8d03dd71' | shasum -a 256

4273df50665b548a834b10146e0060b8ab91db77e9eaa52d10b56b0ffa538e03  -

$ printf %s 'https://www.python.org/ftp/python/3.15.2/Python-3.15.2.tgz' | shasum -a 256

359e63b8b8bba64d7ca774153665b738b7481678eb6d66f4ececa1b612314060  -
```

さっきの`brew --cache python@3.15`で保存先を確かめた`4273df50665b548a834b10146e0060b8ab91db77e9eaa52d10b56b0ffa538e03--python@3.15--3.15.2.arm64_tahoe.bottle.tar.gz`の先頭が`427..`でBottleの`ghcr`と一致する。

どちらを使うかの判定は、[`Library/Homebrew/formula_installer.rb:258`](https://github.com/Homebrew/brew/blob/8f10429b56be28a25032b87463fffc95e556b5bc/Library/Homebrew/formula_installer.rb#L258)

```rb
def pour_bottle?(output_warning: false)
  return false if !formula.bottle_tag? && !formula.local_bottle_path
  return true  if force_bottle?
  return false if build_from_source? || build_bottle? || interactive?
```

`python@3.15`には`arm64_tahoe`のBottleがあるので、通常はBottleを使う

## Bottleとは

ここまで進めてきて、Bottleとは何か改めて確認

公式ドキュメントを読むと
https://github.com/Homebrew/brew/blob/8f10429b56be28a25032b87463fffc95e556b5bc/docs/Bottles.md

> Bottles (Binary Packages)
>
> Bottles are produced by installing a formula with `brew install --build-bottle <formula>`
> and then bottling it with `brew bottle <formula>`.

タイトルに書いている通り、ビルドした結果のバイナリのパッケージである。
手元で確認して実行ファイルであることが確認できた。

```console
$ file /opt/homebrew/Cellar/python@3.15/3.15.0/bin/python3.15
/opt/homebrew/Cellar/python@3.15/3.15.0/bin/python3.15: Mach-O 64-bit executable arm64
```

※`python@3.15`の最新版は3.15.2だけど、過去にインストールした3.15.0が手元に入っている

## ダウンロード後の処理

最初の疑問に戻って、`brew install`のダウンロード後の処理を追ってくことにする

```text
ダウンロード → ① pour（Cellarに展開） → ② link（使える場所にリンク）
```

今回は①の`pour`だけ読む

### 1. Cellarへ展開する

[`Library/Homebrew/formula_installer.rb:1691`](https://github.com/Homebrew/brew/blob/8f10429b56be28a25032b87463fffc95e556b5bc/Library/Homebrew/formula_installer.rb#L1691)

```rb
HOMEBREW_CELLAR.cd do
  ...
  formula.rack.mkpath
  ...
  # Discard anything unexpected under the temporary Cellar path, then
  # verify and extract afresh, refetching if the cached bottle is corrupt.
  downloadable_object.purge_staged_from_download_queue
  downloadable_object.stage
```

`HOMEBREW_CELLAR`に、移動し、`python@3.15`のフォルダを作って、Bottleを展開する

```console
$ brew --cellar

/opt/homebrew/Cellar
```

`HOMEBREW_CELLAR`はApple Siliconのmacの場合、`/opt/homebrew/Cellar`

### 2. インストールの記録を残す

[`Library/Homebrew/formula_installer.rb:1717`](https://github.com/Homebrew/brew/blob/8f10429b56be28a25032b87463fffc95e556b5bc/Library/Homebrew/formula_installer.rb#L1717)

```rb
tab = Utils::Bottles.load_tab(formula)
...
tab.poured_from_bottle = true
tab.installed_on_request = installed_on_request?
tab.time = Time.now.to_i
tab.aliases = formula.aliases
tab.arch = Hardware::CPU.arch
...
tab.write
```

ここで、Bottleからダウンロードした、時間、エイリアス、アーキテクチャという情報を残す

### 3. 実際の場所に書き換える（1749行目）

[`Library/Homebrew/formula_installer.rb:1749`](https://github.com/Homebrew/brew/blob/8f10429b56be28a25032b87463fffc95e556b5bc/Library/Homebrew/formula_installer.rb#L1749)

```rb
keg.replace_placeholders_with_locations(tab.changed_files, skip_linkage:, linkage_files: tab.linkage_files)
```

`@@HOMEBREW_PREFIX@@`などの仮の文字列を実際のパスに置き換える処理
